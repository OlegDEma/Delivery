# Незакриті хвости (станом на 26.08.2026)

## 1. Прийом оплати під сесією ВОДІЯ — не перевірено наживо

**Що зроблено:** причина блокування знайдена — `FINANCE_ROLES` не містив
`driver_courier`, тому API віддавав `403 Forbidden`, а UI показував це як «заборону дії».
Додано `PAYMENT_ACCEPT_ROLES` (super_admin, admin, cashier, driver_courier):
- `POST/DELETE /api/parcels/[id]/payment` — оплата за посилку
- `PATCH /api/passengers?id=...` — водію дозволено міняти **лише** `isPaid`

**Що лишилось:** зайти водієм (Test2) і клікнути обидві оплати. Механізм перевірено
суперадміном і на рівні API, але саме під водієм — ні.

## 2. Viber на реальному телефоні

Клієнт скаржився (ТЗ 17.08): «Вайбер відкривається, але текст не формується».
Виправлено через `viber://forward?text=...` (Viber не вміє номер+текст одночасно)
+ копія тексту в буфер обміну. **Перевірити на реальному пристрої** —
з десктопа це не доводиться.

## 3. Автоматична розсилка SMS/Viber/WhatsApp

Потрібен платний провайдер:
- SMS + Viber — TurboSMS/SMSClub (`TURBOSMS_TOKEN`, `TURBOSMS_SENDER`, `TURBOSMS_VIBER_SENDER`)
- WhatsApp — окремий WhatsApp Business API (`WHATSAPP_TOKEN`)

Код уже готовий: `src/lib/services/messaging.ts` сам перемкнеться на серверну
відправку, щойно зʼявляться ключі (`isChannelConfigured()`), UI бере стан із
`GET /api/parcels/[id]/send-confirmation`. Клієнту сказано, що це окремий етап у кінці.

## 4. Тестовий запис у логу прод-БД

Під час перевірки логування створився запис в історії посилки «137 Львів»:
WhatsApp-підтвердження Відправнику (реально не надсилалось). Якщо заважає — прибрати.

## 5. Технічний борг

- ~21 пре-існуюча помилка `react-hooks/set-state-in-effect` у старих компонентах.
  Білд проходить, але наступний апгрейд React/Next може зробити її фатальною.
- `weightType='actual'` у старих тарифах не відповідає ТЗ §8 (береться максимум
  замість комбінації часток). Деталі — `references/pricing.md`.
- Мульти-локація захардкожена (`at_lviv_warehouse`, `at_eu_warehouse`) — якщо
  відкриють офіс у Києві, схема ламається. Деталі — `references/locations.md`.
